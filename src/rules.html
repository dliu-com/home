Home Task Rules

These rules explain how task records work on this website.

Tasks

  1. Record laundry after starting it.
  2. Record guinea pig cleaning after cleaning the cage and surrounding kitchen area for all six guinea pigs.
  3. Record hanging clothes after hanging up the clothes.
  4. Record Kaka teeth brushing after Kaka's teeth are brushed.
  5. Laundry has a rolling 40-hour target.
  6. Guinea pig cleaning has a rolling 70-hour target.
  7. Hanging clothes has a rolling 45-hour target.
  8. Kaka teeth brushing has a rolling 100-hour target.

Recording a task

  1. The server records the time; the time on the visitor's device is not used.
  2. Two records for the same task cannot be created within one hour of each other.
  3. Recording one task does not prevent any other task from being recorded.

Deleting a record

  1. A record can be deleted only when it is less than one hour old.
  2. The website asks for confirmation before deleting a record.
  3. After one hour, the Delete button is removed and the server rejects deletion attempts.

History and access

  1. Each history displays its 10 most recent records, newest first.
  2. Displayed times use the visitor's local time zone.
  3. Anyone with access to this website can record tasks and delete eligible records.
